Solid/outlined/ghost CTA button — use for every clickable action on the marketing site (hero CTAs, form submit, nav links styled as buttons).

```jsx
<Button variant="primary" size="lg">Book a strategy call</Button>
<Button variant="secondary">Get in touch</Button>
<Button variant="ghost" icon="→">Discover How We Work</Button>
```

Variants: `primary` (solid teal, black text, main CTA), `secondary` (outlined, transparent), `ghost` (text-only, teal, used for inline arrow links). Sizes: `sm`, `md`, `lg`.
